# Alarmon Auto Garage — Demo

İzmir'deki Alarmon Auto Garage için hazırlanan, araç sahiplerini hızlıca bilgilendirip teklif talebine yönlendiren mobil uyumlu tanıtım sitesi.

[Canlı demoyu görüntüle](https://alarmon-auto-garage-demo.pages.dev/)

## Öne çıkanlar

- PPF kaplama, cam filmi, seramik kaplama ve detaylı bakım için net bilgi mimarisi
- Araç bilgisine göre teklif almaya yönlendiren güçlü çağrı alanları
- Gerçek uygulamaları öne çıkaran görsel odaklı sayfa yapısı
- Mobil menü, erişilebilir etkileşimler ve özel 404 sayfası
- Cloudflare üzerinde hızlı ve güvenli yayın

## Teknoloji

- Next.js
- React
- TypeScript
- Tailwind CSS
- Cloudflare / Vinext

Bu çalışma bir müşteri sunum demosudur.
